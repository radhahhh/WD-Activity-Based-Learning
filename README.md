Web Development Activity-Based Projects
This repository contains three beginner-friendly front-end website
projects created as part of a web development activity.
Projects
1. Foodie --- Online Food Ordering Website
A simple food ordering interface where users can: - View food items and
descriptions - Check prices - Explore special offers, including a 20%
discount on the first order - Read customer reviews - Click Order
Now buttons
2. ShopEasy --- Online Shopping Website
A basic shopping interface where users can: - Explore product
categories - View featured products - Check prices and discounts -
Interact with Add to Cart buttons
3. Easy Travel Booking --- Bus and Train Ticket Booking Interface
A front-end interface where users can: - Explore bus and train
services - Check ticket fares - Enter passenger details - Select seats

Important: The travel booking project is a basic front-end
interface. Real-time search, seat availability, payments, and booking
confirmation are not connected to a live booking system.
Technologies Used
- HTML5 --- structures the web pages
- CSS3 --- styles page layouts, colors, and visual elements
- JavaScript --- listed as a learning topic for the shopping
  project; the presentation does not specify its exact functionality
Getting Started
1. Download or clone the project repository.
2. Open the project folder.
3. Locate the main HTML file for the website you want to view (for
   example, index.html, if that is the filename used in your
   project).
4. Open the HTML file in a modern web browser.
If a project uses external CSS, keep its stylesheet in the expected
location and preserve the filename referenced by the HTML file.

Project Scope and Limitations
These projects demonstrate front-end web development concepts. Buttons
and forms may be interface elements only unless their behavior has been
implemented in JavaScript and/or connected to a backend service. The
presentation does not describe a backend, database, payment gateway, or
live booking integration.
